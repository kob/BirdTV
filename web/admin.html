EPG 加载策略说明

自动匹配： 根据频道名称自动匹配 EPG 数据，适用于标准命名的频道

手动绑定： 手动指定频道与 EPG 源的对应关系，适用于特殊命名的频道

自定义映射： 设置频道名称与 EPG ID 的映射关系，提高匹配准确率

智能学习： 系统自动学习用户手动绑定记录，优化自动匹配结果
